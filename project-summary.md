# Система онлайн-записи для шиномонтажа: краткое описание

## Проблема
Запись ведётся в тетради. Двойные записи, очереди в сезон, простой боксов, ручные расчёты.

## Решение
Сайт с базой данных. Поэтапно: сначала таблица Excel для расчётов, затем сайт онлайн-записи с учётом работ.

## Допущения
- Один салон, 2 бокса, работа с 8:00 до 19:00.
- Услуга занимает бокс на 1,5-3 часа, примерно 7-14 клиентов в день, ориентир 10.
- Все записи (сайт, звонок, живой визит) идут через единое расписание.
- Если нужного времени нет, система предлагает ближайшее свободное и список ожидания.
- При отмене администратор вручную обзванивает список ожидания.
- Расчёты выручки ведутся в Excel, система выгружает выполненные работы в CSV.

## Роли
| Роль | Доступ |
|------|--------|
| Клиент | Услуги и цены, свободные/занятые слоты, форма заявки |
| Администратор | Заявки, расписание боксов, брони, отмены, список ожидания |
| Владелец | Всё то же + отчёты, выручка, настройки услуг и цен |

## Архитектура
Клиент, администратор и владелец работают через единый веб-сервер, данные хранятся в одной базе (клиенты, записи, услуги, боксы).

## Предложенный стек
Python (FastAPI/Flask) и PostgreSQL или SQLite.

## Границы первой версии
Входит: онлайн-запись, расписание боксов, список ожидания, учёт работ, выгрузка в Excel.
Не входит: онлайн-оплата, автоуведомления, мобильное приложение.
