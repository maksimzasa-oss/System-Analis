# Требования к системе онлайн-записи для шиномонтажа

## 1. Бизнес-цели

- **BR-1.** Убрать двойные записи и простой боксов.
- **BR-2.** Снизить потерю клиентов из-за очередей в сезон.
- **BR-3.** Автоматизировать учёт работ, чтобы выручка считалась без ручного подсчёта.

## 2. Роли

| Роль | Доступ |
|------|--------|
| Клиент | Услуги и цены, свободные и занятые слоты (без данных других клиентов), форма заявки |
| Администратор | Всё то же + входящие заявки, расписание боксов, создание и отмена записей, список ожидания, отметка выполненных работ |
| Владелец | Всё то же + отчёты, выгрузка данных в Excel, настройка услуг и цен |

## 3. User stories

- US-1. Как клиент, я хочу выбрать услугу и свободное время на сайте, чтобы не стоять в очереди.
- US-2. Как клиент, я хочу заранее видеть стоимость услуги для моих колёс.
- US-3. Как клиент, если нужного времени нет, я хочу увидеть ближайшее свободное или встать в список ожидания.
- US-4. Как администратор, я хочу записать клиента, обратившегося по телефону или лично, чтобы все записи были в одном расписании.
- US-5. Как администратор, я хочу видеть расписание двух боксов, чтобы не допустить двойной записи.
- US-6. Как администратор, при отмене записи я хочу видеть список ожидания, чтобы позвонить подходящему клиенту.
- US-7. Как администратор, я хочу отмечать выполненные работы.
- US-8. Как владелец, я хочу выгрузить выполненные работы в Excel, чтобы посчитать выручку.

## 4. Функциональные требования

| ID | Требование | Связь |
|----|-----------|-------|
| FR-1 | Система показывает список услуг с ценой и длительностью | US-1, US-2 |
| FR-2 | Система рассчитывает цену по услуге и размеру колёс | US-2 |
| FR-3 | Система показывает свободные и занятые слоты по двум боксам | US-1, US-5 |
| FR-4 | Система не позволяет создать запись, если все боксы заняты на это время | US-1, US-5 |
| FR-5 | Запись занимает бокс на время, равное длительности услуги | US-5 |
| FR-6 | Если время занято, система предлагает ближайшие свободные слоты | US-3 |
| FR-7 | Система позволяет добавить клиента в список ожидания (имя, телефон, услуга, желаемая дата) | US-3 |
| FR-8 | Администратор может создать, изменить и отменить запись от имени клиента | US-4 |
| FR-9 | При отмене записи система показывает подходящих клиентов из списка ожидания | US-6 |
| FR-10 | Система поддерживает статусы записи: новая, в работе, готова, отменена | US-7 |
| FR-11 | Система хранит клиентов, их авто и историю записей | US-8 |
| FR-12 | Система выгружает выполненные работы за период в CSV/Excel | US-8 |
| FR-13 | Доступ к функциям зависит от роли | все |

## 5. Нефункциональные требования

- **NFR-1.** Сайт корректно открывается на телефоне и компьютере.
- **NFR-2.** Администратор и владелец входят по логину и паролю.
- **NFR-3.** Клиент не видит данные других клиентов.
- **NFR-4.** Расписание на день открывается не дольше 2 секунд.
- **NFR-5.** Данные ежедневно копируются в резервную копию.

## 6. Допущения

- Один салон, 2 бокса, работа с 8:00 до 19:00.
- Около 10 записей в день, 1-2 отмены.
- Одна запись содержит одну услугу.
- Обзвон списка ожидания выполняет администратор вручную.

## 7. Вне первой версии

Онлайн-оплата, автоматические уведомления клиентам, мобильное приложение, несколько салонов.

## 8. Открытые вопросы для владельца

- Точная длительность каждой услуги?
- Как считается цена: только по размеру колёс или есть другие факторы?
- Сколько ждать клиента из списка ожидания, если он не отвечает?
